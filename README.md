# Muon Telescope Remote Control

A four-panel plastic-scintillator cosmic-ray muon telescope that rotates in zenith angle under software control, built around a Raspberry Pi 4.

**Documentation:** https://AG-Schumann.github.io/Muon_Telescope_Remote_Control/ — hardware, installation, architecture, configuration reference, data formats, calibration, troubleshooting.

```
software/   the Python package (daemon, TUI, drivers), config, scripts, systemd unit
hardware/   KiCad board designs, CAD, measurement-setup drawings and photos
docs/       the documentation site (GitHub Pages, Jekyll + just-the-docs)
```
